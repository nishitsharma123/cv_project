# Handwritten Indic-Script Form Digitiser

This workspace hosts the semester project **Handwritten Indic-Script Form Digitiser**, an end-to-end system converting handwritten Devanagari form fields (Applicant Name, Date, Declared Amount) into structured digital records.

---

## Project Structure

All project modules, code, and documentation reside in the primary project folder [`handwritten-form-digitiser`](./handwritten-form-digitiser):

- [`handwritten-form-digitiser/README.md`](./handwritten-form-digitiser/README.md): Project overview, architecture, setup guide, and roadmap.
- [`handwritten-form-digitiser/docs/architecture.md`](./handwritten-form-digitiser/docs/architecture.md): Deep-dive architectural specification, module responsibilities, and data flow diagrams.
- [`handwritten-form-digitiser/docs/implementation_checklist.md`](./handwritten-form-digitiser/docs/implementation_checklist.md): Comprehensive phase-by-phase implementation tracker.
- [`handwritten-form-digitiser/docs/api_contract.md`](./handwritten-form-digitiser/docs/api_contract.md): High-level REST API contract and schema specifications.
- [`handwritten-form-digitiser/backend/`](./handwritten-form-digitiser/backend): Python / FastAPI application, OpenCV pipeline, and PyTest test suite.
- [`handwritten-form-digitiser/frontend/`](./handwritten-form-digitiser/frontend): React, Vite, and Tailwind CSS web application.
